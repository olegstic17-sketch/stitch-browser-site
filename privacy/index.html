Политика конфиденциальности

Версия: 9 ноября 2026 года

Важно: STITCH Browser — настольное приложение, находящееся в разработке. Настоящая политика описывает предусмотренную обработку данных в текущем проекте и должна обновляться при изменении возможностей приложения.

1. О приложении

STITCH Browser — независимый браузер для Windows. Этот веб-сайт предоставляет информацию о приложении, его возможностях и правилах использования. По вопросам обработки данных можно связаться с разработчиком: olegstic17@gmail.com.

2. Данные при входе через Google

Если пользователь выбирает вход через Google после подключения этой функции, Google может передать приложению в пределах предоставленного согласия базовую информацию о профиле: имя, адрес электронной почты, идентификатор аккаунта и изображение профиля. Эти сведения предназначены для входа в профиль и его отображения в интерфейсе приложения.

STITCH Browser не запрашивает доступ к содержимому писем Gmail, Google Диска или к паролям Google. Вход через Google сам по себе не является синхронизацией с Chrome или Google Password Manager.

3. Данные браузера на устройстве

При работе браузера на устройстве могут сохраняться настройки, избранное, история просмотров, файлы cookie и другие данные сайтов в пределах локального профиля браузера. Посещаемые сайты могут самостоятельно собирать данные согласно своим правилам. STITCH Browser не гарантирует анонимность в интернете.

4. Данные веб-сайта

Этот информационный сайт не содержит собственных рекламных или аналитических скриптов. При его посещении поставщик хостинга и сетевые сервисы могут обрабатывать технические данные соединения, например IP-адрес, в соответствии со своими политиками. Сайт может размещаться на GitHub Pages.

5. Передача и безопасность

Данные, передаваемые Google при авторизации, обрабатываются также согласно политике конфиденциальности Google. Передача данных третьим сторонам возможна, когда это требуется для работы используемых сервисов или по закону. Мы не используем данные Google-профиля для рекламной продажи.

6. Управление данными

Пользователь может выйти из Google-профиля в приложении, а также управлять разрешениями сторонних приложений в настройках аккаунта Google. Для запроса об удалении данных, связанных с сервисом, или для вопросов о конфиденциальности напишите на olegstic17@gmail.com. Данные, сохранённые локально на устройстве, могут потребовать отдельного удаления в настройках приложения или системы.

7. Обновления политики

Политика может меняться по мере развития STITCH Browser. Актуальная версия публикуется на этой странице с датой обновления.
